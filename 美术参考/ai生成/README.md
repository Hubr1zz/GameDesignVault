# AI 美术探索索引

本目录包含基于《Hunting in Darkness》现有设计文档生成的 11 套视觉方向。前七套覆盖 `ui`、`概念美术`、`怪物设计`、`插画`、`装备` 五类代表性素材；第 8 至 10 套依据连续反馈收窄为 `ui`、`插画`、`装备` 三张定向验证图，第 11 套只校准仍需调整的插画。

生成方式：Codex 内置 imagegen。全部图片均为原创视觉探索；参考作品只用于完成度、媒介质感和氛围层级，不复刻已有角色、怪物、服装、武器、界面、标识或构图。

## 背景知识

世界内存在实体卡牌、骰子、筹码与桌面交互。

## 共同视觉约束

- 压抑、原始、美。
- 冷暗环境中以少量暖光表现人的意志与感情。
- 中世纪生存文化结合骨、皮、角、手掌等生物加工材料。
- 怪物具有可解释的拟人结构，追求威胁感、陌生感、丑感、或美感，而非血腥恶心。
- 无商标、无水印、无现有作品的可识别资产复刻。

## 长期美术生成需求

### 线条、颜色与体积

- 第 5 版的视觉气质是后续探索的主要完成度参照，但不能继续沿用过于平直、缺乏光影体积的用色。
- 线条是核心造型语言：轮廓线、结构线与顺形排线负责描述剪影、解剖、材质和主要阴影，不能被厚涂或大面积模糊覆盖。
- 整体画面采用参考云图的等质排线方法：人物、服装、建筑、地面、器物、天空和云层都可使用同一套线条逻辑，不再把它限制为云朵的局部对象语言。
- 同一画面内的排线应保持近似一致的粗细、深度和不透明度，每根线都清晰可见。明暗主要由线距和数量控制：阴影面使用更密集、顺应体积的线组，亮面只保留少量稀疏线条和较大色块或留白；禁止用细淡、半透明、雾状或逐渐消失的线条冒充层次。
- 亮面以及完整、方向明确、无需额外解释的平面应主动减少排线，允许形成接近纸面留白的安静色块。此类区域只保留轮廓、边缘转折和极少量必要结构线，不能为了维持“线条感”而重新铺满纹理。
- “全画面使用同一线条逻辑”不等于所有区域具有相同纹理频率。排线方向必须解释曲面或平面，密度必须服从明暗；主体仍保留半厚涂色块，避免机械铺满高频细纹。
- 线条层和颜色层必须职责分离：清晰、连续、等粗等深的线条负责轮廓、结构与必要排线；颜色负责大体积、材质分区和普通明暗过渡。禁止用细碎色斑、短笔触、颗粒阴影或许多微小明暗块模拟线条感。
- 人物尤其需要控制信息频率。服装、护甲、头发、绑带、伤口与褶皱优先合并成少量连续的大色块，只保留对剪影、动作、受力和主要结构有用的线条；不要同时堆叠碎裂轮廓、微小色差和杂乱短线。
- 允许在画面的小部分区域使用较柔和、略带模糊的颜色过渡，例如受光面、轮廓光、反射光、雾层、半透明材质和发光焦点，以增强立体感与空间层次。
- 柔和渐变应具有明确的光源或材质依据；远离焦点后应重新回到清晰线条、平涂色块或留白，避免整张画面转为写实厚涂。
- 可依据内容略微改变线条密度、体积感、抽象程度和用色数量。每组探索应记录这些参数，差异必须服务于可读性、情绪或材质，而不是随机换风格。

### 云朵排线

- 云朵是全画面排线方法的主要参照：使用层叠、圆弧状的外轮廓组织体块，并以沿云团曲面弯曲的等粗、等深短弧线表现内部转折；暗面线距更近，亮面仅保留少量弧线。
- 云层可以在线条下方叠加柔和、低饱和的灰蓝或暖灰色阶，以保留第 7 版提出的色彩体积感；色块必须位于线条层级之下，不能把弧形结构线冲淡。
- 云朵暗部使用宽阔、连续、普通的低饱和颜色过渡，不使用颗粒、碎色块、破碎笔触或短小色痕制造伪排线。云层的“线条感”只能由上层清晰线条产生，不能由底层颜色纹理替代。
- 人物、服装、建筑、地面和装备应把云朵的规则转译为顺应自身结构的平行线组；它们可以改变线条方向和密度，但不能改变线条的可见度、粗细与不透明度。

### 装备细节层级

- 装备首先依靠剪影、功能结构和少量主要材质分区建立辨识度，不追求写实渲染式的零件穷举。
- 合并不影响功能辨识的小甲片、铆钉、裂纹、刻花、接缝和绑带；次要细节用少量细线或较大的色块概括。每件装备应形成数个清晰大形，避免过度锐利、过度清晰和高频材质噪声。
- 装备线条偏向干净的漫画墨线：优先使用连续、清晰、较长的轮廓线和结构线，减少过短、过淡、断续、随机的刮擦纹。暗部可使用小组平行排线，亮部以大色块和少量线条为主。

### UI 素材定义

- `ui` 指可直接进入 UI 制作流程的独立视觉素材，不是玩家视角下的完整游戏画面，也不是带场景、角色和所有信息层级的界面效果图。
- 优先生成卡牌边框、角花、面板边缘、分隔花纹、插槽外框、按钮外沿、页签装饰等可拆分组件；应保留空白内容区，并尽量使用透明背景、清晰切边和彼此分离的布局。
- UI 装饰采用基础、克制的巴洛克卷草、叶饰和对称曲线。图片边框必须细窄以避免遮挡内容，但“细窄”只限制占用宽度，不等于退化为纯线框；窄边带内部仍需形成连续、清晰可辨的叶卷、C/S 涡卷与对称节奏，角部可略丰满，长边保持低矮而连贯的花纹。
- 花纹下方可保留窄条相框式承托底框，但底框只向外侧缩窄：面向内容区的内沿和内容开口保持不变，花纹的叶尖、卷曲和不规则外轮廓应略微越出底框，避免外边缘呈现完全方正的矩形感。
- UI 颜色以墨黑、骨白、暖灰和灰褐等朴素色为主，禁止大量金色、红色、宝石、发光点和高饱和材质争夺信息焦点。
- 图片边框不加入手、五官、花朵、荆棘、骨骼、人物或其他主题物点缀。若未来需要这些主题元素，应作为独立装饰素材另行提出，不能默认塞入基础边框。
- 禁止把完整 HUD、桌面棋局、角色工坊场景或战斗屏幕仅因含有面板而归入 `ui`。完整界面效果图如需生成，应另行标记为界面概念，不替代 UI 组件素材。

## 使用边界

- 这些图片是视觉方向探索和内部概念素材，不是可直接发布的最终 UI 或本地化卡面。
- 部分怪物概念板包含模型自动生成的英文说明文字；正式制作时应重新排版和本地化。
- UI 组件图可用于验证材质语言和装饰体系，但仍需在正式制作时拆分、清边、九宫格化并适配目标分辨率；完整界面的信息层级和交互线框应另行设计。
