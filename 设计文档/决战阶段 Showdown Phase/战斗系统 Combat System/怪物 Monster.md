# 怪物 Monster

## 文档用途

本页定义怪物在战斗中的数据构成、出牌方式、目标选择、部位卡与Buff逻辑。纯战斗流程请参考[[设计文档/决战阶段 Showdown Phase/战斗系统 Combat System/战斗系统 Combat system (索引)|战斗系统]]。

## Boss构成

- 基础行动：可能不止一张。
- 一套行动卡：所有攻击和技能都用行动卡表示。除非被抽取，不需要提前展示完整内容。
- 部位卡：被攻击时抽取。
- 特性卡槽：常驻被动或特殊状态。
- Buff槽：战斗中的临时状态。
- 战斗数据：
  - 韧性：猎人的攻击是否容易造成有效伤害。
  - 血量：每次受到有效伤害时被削减。

## 怪物回合与行动执行

### 执行行动

回合开始时，翻开行动牌堆顶的行动卡并执行。

### 攻击结算

当攻击行动卡被翻开时，按该卡的数据对目标进行攻击。每次怪物攻击猎人时，为每个目标单独构建临时牌堆：

- 怪物精准张“命中”
- 目标猎人敏捷张“闪避”

每次抽取前都要重置牌堆。UI表现建议为快速抽牌、重洗、再抽，直到完成该攻击的次数。

命中后，需要逐张保留命中结果，再揭示对应受击部位，进入猎人受伤流程：[[设计文档/决战阶段 Showdown Phase/战斗系统 Combat System/战斗系统 Combat system (索引)#猎人受到伤害|猎人受到伤害]]。

### 目标选择

怪物行动的目标选择建议拆成四类：

- 不需要指定目标的技能，例如给自己Buff。
- 指定格子为目标的技能，对范围内所有单位生效。
- 指定方向的范围攻击。
- 直接指定猎人为目标的技能，例如最近、最远、伤势最重的猎人。

常见锁定方式：

- 最近的猎人
- 损伤最严重的猎人
- 随机指定固定编号
- 完全随机指定猎人

## 被攻击时的交互

### 受到攻击

猎人攻击命中后，每次命中会展示一张部位卡。投掷出攻击强度后，玩家需要把命中分配到不同部位卡上，再依次结算对应效果。

### 受到伤害

如果攻击成功突破韧性并满足部位卡条件，怪物会扣减血量或部位耐久。

## [[术语词典/打击部位|部位卡]]

- 血量：部位卡拥有独立血量。每次造成伤害时默认减少1点；血量归0时被摧毁并移出游戏。
- 条件：部位卡的效果会根据条件触发。不同Boss可以定义不同条件，例如永远触发、攻击成功时、攻击失败时、被摧毁时。
- 条件覆盖：同一张卡有多个条件时，需要明确优先级。例如暴击不会再触发普通成功效果。
- 效果：常见效果包括反击、掉落素材、施加状态、改变行动节奏。

例子：

- 失败：反击攻击者。
- 暴击：掉落素材。

## 怪物行动卡

怪物的主动能力也由卡牌呈现，但怪物不需要像猎人那样暴露全部手牌。

行动卡分为攻击型和非攻击型：

### 攻击型

带有攻击效果的行动卡。

攻击由4个属性构成：伤害、精准、次数、时点。

目标选择通常分为：

- 不需要指定目标的技能，例如给自己Buff。
- 指定格子为目标的攻击。
- 指定方向的范围攻击。
- 直接以猎人为目标的攻击。

### 非攻击型

带有各种非攻击效果的行动卡，例如移动、叠加Buff、改写牌堆、制造场地效果等。

## Buff

- 力量：获得对应层数的力量，可以为负。
- 闪避：获得对应层数闪避，可以为负。
- 动能：下次移动时消耗，额外移动1。
- 防守：无视下一个到来的命中，持续到自己下个回合。
- 专注：通过集中获得，下个回合得到额外时点。
