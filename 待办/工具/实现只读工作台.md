# 实现只读工作台

工作台的第二个增量。命令层（`vault.py` 的 `index`、`context`、`rename`、`images`、`lint`）已完成，工作台只读取它生成的索引。

已确定的方案：

- 后端：在 `vault.py` 里加 `serve` 子命令，用 Python 标准库的 HTTP 服务，只监听本机。
- 前端：Vite、React、TypeScript，代码放在仓库根目录的隐藏目录 `.workbench/`。
- 前端的所有读取都必须能从一份静态索引完成，这样可以由持续集成构建成只读网站。
- 图片看板的缩略图由 Pillow 预生成到不进版本库的缓存目录。

三个视图：

- 文档页加关系侧栏：正文，以及按类和状态分组的反向链接、相关待办和图片。
- 美术看板：按图集、类别和状态浏览、筛选、并排对比。
- 收件箱：新灵感、未解决问题、占位案例、待办和 lint 结果。

开工前需要确认：美术看板的默认布局是按轮次对比还是按主题汇总。
