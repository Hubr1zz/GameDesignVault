# 狩猎阶段噪音值系统

Idea Birthday: 2026年6月5日 03:22

## 概念

狩猎阶段探索地图时，每个猎人根据自身装备与特性拥有不同的**噪音值**。噪音值越高，越容易触发地图事件。

## 表现层（卡牌化）

每点噪音值对应一张噪音卡，加入洗混的牌堆中。每个猎人的噪音卡可标记归属（对应下方的抽取互动方式）。

## 互动方式

### 方式一：合并阈值判定

将全队所有猎人的噪音值叠加，判断总和是否超过某个阈值——超过则触发事件。适合表现「整体行动多嘈杂」的场景。

### 方式二：抽取归属判定

从所有猎人的噪音卡混合后的牌堆中，抽取固定数量的噪音卡。每个猎人根据**自己有多少张噪音卡被抽中**，触发对应不同程度的结果（例如：0张=安全，1张=轻微，2张+=严重）。适合表现「谁更嘈杂，谁承担后果」的差异化场景。

## 设计方向

- 噪音值可成为装备/特性选择的隐性权衡维度：高噪音装备往往更强力，但会增加探索风险
- 事件触发结果可以是中性的（遭遇、发现线索）而非纯负面，避免让低噪音成为唯一「正确」选择
- 两种互动方式可混用，根据具体事件类型选择不同判定逻辑
