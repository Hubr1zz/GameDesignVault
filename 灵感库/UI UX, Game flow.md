# UI/UX, Game flow

Idea Birthday: 2026年5月10日 02:42

- 抽卡时，类似3D空间下展示杀戮尖塔的手牌，玩家鼠标悬浮的牌被置于顶层。点击后，卡牌慢慢靠近屏幕，同时旋转翻面。
- 点击角色显示3D canvas，包含角色的信息。所有需要显示的信息包含：
    - 基础信息：鼠标悬浮时，相机靠近放大面板。
    - 装备栏：平时只显示图标和名字。鼠标悬浮时，卡牌变大并显示额外信息。
    - 行动卡：平时只显示图标和名字。鼠标悬浮时，卡牌变大并显示额外信息。
    - 资源：
        - 战斗灵感：待设计。
        - 命运值：待设计。
        - 意志值：待设计。
    - 状态栏：
        - 临时状态栏：平时只显示图标和名字。鼠标悬浮时，显示额外信息。
        - 永久状态栏：平时只显示图标和名字。鼠标悬浮时，显示额外信息。
    - 场地信息：比如时点。

- 教程
    
    开局直接让玩家经历一次预设好的小战斗作为教程。中途教会玩家战斗和探索机制。
    
    以讲故事的形式呈现：你和你的朋友从黑暗中醒来，进行简单探索→收集到基础武器→听到嘶吼声，前去查看→另外两个人在和一个生物战斗。决定帮助他们一起战斗→战斗教程。
