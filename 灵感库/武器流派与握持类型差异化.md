# 武器流派与握持类型差异化

武器通过专属规则与专属[[行动卡]]形成流派差异，同时继续复用现有攻击、[[时点]]、部位与行动卡系统。

## 武器流派

| 武器 | 核心特色 | 专属规则与行动方向 |
| --- | --- | --- |
| 剑 | 全能、适应不同情况 | 攻击前在速度、穿甲、攻击后移动等收益中选择一项；行动方向包括变招、格挡反击、踏步斩。 |
| 弓箭 | 命中、精准暴击 | 瞄准已暴露或指定部位；满足瞄准条件时降低形成暴击所需的成功结果；行动方向包括瞄准、蓄射、弱点射击。 |
| 拳 | 速度、暴击、连续攻击 | 通过高速度形成多次攻击；忽略同一次攻击中的第一次反击；行动方向包括连打、贴身、收势。 |
| 锤子 | 穿甲、破坏防御 | 获得额外穿甲，多余穿甲可用于破坏超级护甲或部位耐久；行动方向包括蓄力重击、震甲、砸倒。 |
| 矛 | 叠加Buff、暴击率成长 | 连续攻击成功时在“心流”状态上叠加Buff，消耗层数强化暴击；行动方向包括架势、追击、贯心。 |
| 盾 | 生存与免疫伤害 | 通过主动防御免疫下一次伤害来源，而非获得常驻伤害免疫；行动方向包括完美防御、护卫、盾击。 |

拳的无视反击与盾的伤害免疫应由行动或限定次数触发，避免永久移除Boss部位反击或攻击机制。

## 武器与装备类型

- 重武器：只能双手持有，增加攻击的时点消耗并获得力量或穿甲加成。
- 双手武器：占用两个武器格。
- 普通武器：具体通用收益尚未确定。
- 双持武器：双持是独立武器标签，不是所有单手武器均可使用的通用规则。
- 双持武器在两个武器格中装备两把相同装备时获得速度加成。
- 除双持武器外，猎人最多可以装备两把不同武器。
- 双持时，每一把武器分别提供一张行动卡。

## 新属性方向

- 力量：影响穿甲和探索阶段的力量型互动成功率。
- 敏捷：影响战斗与探索阶段的移动，以及战斗中的闪避。
- 技巧：影响命中和探索阶段的技巧型互动成功率。
- 幸运：暴击率和全狩猎事件成功率

## 武器变钝

部分怪物部位会使锋利武器获得“变钝”。变钝不叠层，并降低武器的穿甲或暴击能力。

变钝后获得临时“研磨”行动：花费3时点和1点武器耐久，移除变钝。
