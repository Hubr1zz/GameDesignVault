# 狩猎阶段地图探索系统：地形卡与小地块

Idea Birthday: 2026年6月5日 03:37

## 大地块层：地形卡与道路

地图由**地形卡**组成，地形卡之间由线条相连，代表道路。每张地形卡可配置链接多条道路。

道路上有符号，不同符号对应不同效果，例如：

| 符号 | 效果 |
| --- | --- |
| 危险 | 包含事件，例如根据噪音值触发战斗 |
| 未知 | 通用随机事件 |
| 地块事件 | 从地块事件池抽取 |
| 花费变化 | 减少或增加经过时的体力消耗 |

（道路符号类型可继续扩展）

## 小地块层：进入地形后的细节玩法

每张地形卡内部由小地块组成（暂定 10×10 格子），小队进入地形卡后进入独立的小地块玩法。

### 核心机制——类扫雷翻开

- 玩家选择一个起始位置并翻开
- 翻开后可继续翻开周围地块，部分地块有特殊翻开规则
- 整体类似扫雷的逐步揭示逻辑

### 地块规则（按地形类型配置）

每种地形卡有自己的小地块规则，例如：

> **沼泽**：翻开小地块时，进行骰子判定，失败则减少体力
> 

### 离开条件（暂定）

每种地形卡有一种特殊的**「离开」地块**，翻开该地块后才允许小队离开此地形。不同地形可设计不同的离开地块与条件。

## 设计方向

- 道路符号系统与噪音值系统（见《狩猎阶段噪音值系统》）可深度联动：高噪音队伍更容易触发「危险」符号
- 小地块玩法为每种地形提供独特的探索体验，避免所有地形感觉相同
- 「离开」地块作为隐藏目标，增加探索的目的感，同时保持不确定性
