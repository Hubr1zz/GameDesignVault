# Event inspiration

Idea Birthday: 2026年5月10日 02:42

- 事件
    - 事件触发，让玩家修改一个角色名字成XX。很久之后触发事件问记不记得他的名字，如果记得，获得秘密战斗技艺。
    - 强大的存在上门让你派人进行高难度挑战，失败获得严重惩罚，参加的人越多，越简单，但奖励越少。如果只派出一个人并通过挑战，获得秘密战斗技艺。
    - Boss战和你玩某种俄罗斯转盘，如果通过这个方法战胜boss，获得秘密战斗技艺。
    - 适用于：战斗灵感每回合保留。当保留某个战斗灵感超过X回合，判定。
    - 某个容易被暴击的boss战中连续造成暴击3次，判定。
    - 基于韧性设定：连续造成有效攻击（超过韧性）3次，判定。
    - 战斗经验满时，判定
    - 累计通过三次死亡检测，判定。
    - 其他队友全部死亡且自己重伤时，判定。
    - 事件要求你上交一件物品，如果上交带有某个词条的物品，解锁后续。
    - 事件判定触发，获得约定之物；后续战斗遭受攻击时可以选择丢弃物品来抵消本次伤害；受到重伤时，如果物品还在身上，判定，如果失败，失去物品抵消伤害，如果成功，回忆起曾经和重要之人的约定，获得战斗技艺。
    - 当物品可传承，并传承达到一定次数时，判定。
    - 你看见一个人身上带满了剑，他邀请你进行比试，胜利了可以获得剑，失败了失去剑，也可以选择和他战斗。需要设计一个卡牌机制，最好和战斗机制共享。比如提高剑的熟练度/某个剑的战斗技艺会叠层，在抽取闪避卡时，如果没有命中，则XX。需要设计。
    - 某个特性会说你觉得自己与众不同。某些条件下（比如重伤判定时、特殊攻击时）额外判定：
        - 成功：获得秘密战斗记忆。
        - 失败：就无事发生。
        - 大失败：失去这个特性，获得悲伤特性。“你发现这只是你的幻想”。
    - 当角色遭受大危机且有某个特性时触发事件：当你做不到你想要做到的事时，这种落差感淹没了你。没有人知道这是怎样巨大的痛苦，你必须独自面对。判定，成功则获得巨大奖励，失败受到大惩罚。
    - 战斗事件，和某个以悲伤为主的人形boss战斗时，如果你拥有狂妄，狂笑症，或者战胜悲伤特性，可在boss出某一招强力攻击时触发事件“对决”：前置描述“如果判定成功，你并没有躲闪，而是站在原地…”。如果判定成功，完整描述“当攻击快要击中时，你轻松地挡下了他的攻击，在他震惊的目光中反击，造成了巨大的伤害” 如果Boss被这招杀死，获得额外奖励。
