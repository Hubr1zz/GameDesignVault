# 行动卡槽位置排列机制

Idea Birthday: 2026年5月28日 02:35

角色的行动卡槽有固定的位置结构，例如：

| 排 | 卡槽数 |
| --- | --- |
| 第一排 | 2张 |
| 第二排 | 4张 |
| 第三排 | 2张 |

总计上限固定为8张。

**核心规则**：每回合开始时，**只有第一排的卡会自动重置为正面**，第二、三排的卡需要通过其他方式恢复。

**设计影响**：

- 玩家需要主动管理哪些卡放在哪一排，权衡"高频率但数量少"的第一排与"强力但难恢复"的第二三排
- 行动卡槽的物理位置成为角色构建的一个独立维度
- 可引申出"换位"行动：将卡从第二排移至第一排（或反之），作为消耗时点的主动操作
