# 特殊特性关键词文案

部分特殊[[特性]]可以使用”性格“关键词标记：

- 狂妄：你的自命不凡让野心无限膨胀。所以你的报复与追求，这黑暗束缚不住。
- 自卑：你觉得自己低人一等，自我怀疑。所以始终渴望进步，保持尊重。
- 傲慢：你鄙视一切平庸，包括自己。所以你的内心始终保持强大。
- 急躁：你急于求成，被冲动控制。所以你抓住每一个间隙证明自己。
- 鲁莽：你不懂得权衡风险。所以你勇于面对一切。
- 疯狂：你的热情小众又古怪。所以你始终热爱这个世界。
- 懦弱：你胆小如鼠，将世界视为威胁。所以你准备充分，时刻谨慎。 

狂妄傲慢疯狂属于黄色，急躁鲁莽红色，自卑懦弱蓝色，不同事件根据不同颜色触发负面效果，但增加内化点数。

现有[[Narrative inspiration]]中已经记录狂妄、傲慢与自卑的其他文案或效果
