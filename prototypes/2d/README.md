# Boss 战斗网页原型

这个目录是一个无依赖、无构建步骤的 HTML 原型，用来验证 `设计文档/决战阶段 Showdown Phase/战斗系统 Combat System/` 中的 Boss 战斗循环。

## 运行方式

直接打开 `index.html` 即可。也可以在本目录启动任意静态服务器。

## 已覆盖机制

- 玩家/怪物回合轮换
- Boss行动按“前摇应对 → 行动执行 → 后摇确认”三阶段推进，并公开有限行动队列
- 前摇中时点投入最高的猎人需要等待至少一名队友追平后才能继续行动
- 战前配置页选择猎人卡、Boss行动卡、部位卡，并查看卡牌效果
- 怪物公开行动卡与时点上限
- 怪物回合手动执行已翻开的行动卡
- 怪物行动目标模式：自动锁定、指定目标格、指定方向、直接指定猎人
- 猎人行动卡正面、翻面、恢复、爆发
- 思维区临时资源：红、蓝、黄色战斗灵感以色块显示，同色资源用数字叠层
- 基础行动【专注】：消耗2时点，掷两枚三色骰并获得对应战斗灵感
- 行动卡主动恢复、被动恢复与恢复失败反馈
- 攻击、移动、转向、意志行动
- 耗尽、结转、超时
- 鼓舞指定猎人，消耗意志给予时点并帮助脱离超时
- 猎人攻击 Boss 的临时成功/失败牌堆
- 抽到的攻击结果手动分配给展示出的部位卡
- 部位卡抽取、顺序结算、成功/失败/摧毁/持续部位
- 怪物攻击猎人的命中/闪避临时牌堆
- 受击部位、伤害、重伤/永久损伤记录
- 致命伤后的死亡牌堆、玩家选牌与生还判定
- 武器速度、威力、范围
- Boss Buff、特性槽、时钟槽、镜像槽
- Boss 力量、闪避、动能、防守、专注、护甲 Buff 的原型效果
- 草丛、石块、边界与撞击伤害
- 战前可选择四边形地图（4方向、曼哈顿距离）或六边形地图（6方向、六边格距离）
- 石块地形临时行动：投石
- 战场单位：不可穿越、不可重叠的可破坏物体
- 可破坏物体：攻击/撞击扣耐久，破坏后移出并给奖励
- 浏览器调试入口：`window.combatPrototype`
- 浏览器内自测入口：`runCombatPrototypeSelfTest()`

## 文件结构

- `index.html`：静态入口。
- `data.js`：当前 Boss、猎人、行动卡、部位卡和战场数据。
- `app.js`：规则引擎与 UI 渲染。
- `self-test.js`：无依赖核心规则自测。
- `styles.css`：简单 2D UI 样式。

## 原型假设

- 护甲阻挡位置未在正式文档中完全定义；当前实现为命中后再抽护甲阻挡牌堆。
- 暴击未定义；当前只实现成功、失败、摧毁和持续部位。
- 转向在 2D UI 中暂不改变朝向，只作为低时点动作验证翻面节奏。
- 前摇/后摇先作为公开预告与时点差异，没有打断窗口。
- 意志行动【硬撑】在正式文档中仍是暂未细化；当前原型显示为禁用按钮。
