# Hunting in Darkness · 3D 决战原型

独立于 `prototypes/2d/` 的桌面浏览器 3D 战斗纵切片。它实现正式战斗规则，以及本轮指定的思维区、Boss 操控偏移与命运值、进阶部位卡、死亡牌堆/存活事件/生存卡机制。

## 运行

```powershell
npm install
npm run dev
```

生产构建与静态预览：

```powershell
npm run build
npm run preview
```

规则测试：

```powershell
npm test
```

## 操作

- 右键拖动旋转镜头，中键平移，滚轮缩放。
- 点击猎人聚焦头部切面的 3D 卡桌；点击空白战场、“退出头脑卡桌”或按 `Esc` 返回进入前的镜头。
- 思维、行动和意志行动均为可点击的 3D 实体卡。行动卡左键使用/恢复，正面行动卡右键爆发。
- 顶部“配置”可实时调整脑桌仰角、相机观察仰角、脑桌大小和观察距离。
- 使用需要费用的行动前，先点击思维区中的一张灵感卡。
- 移动时先选择灵感并点击移动卡，再点战场上亮起的相邻格；转向时点击角色周围的六方向箭头。
- 专注骰子会在角色身边落入战场；骰子稳定前镜头与场景输入保持锁定。
- 攻击时先选结果卡，再点部位卡完成分配；部位卡可拖动换序。
- Boss 回合中，红色幽灵表示合规落点。可以改选终点或目标并承担命运值。

## 原型边界

- 护甲采用显式标注的原型假设：受击部位确定后，以该部位护甲与 Boss 精准构建阻挡/穿透临时牌堆。
- 命运值只累积并写入战后报告，本场不产生即时数值影响。
- 不包含时点联动、Boss 时钟/镜像、集中攻击骰制、暴击、战役存档或移动端专项适配。
