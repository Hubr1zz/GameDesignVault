# Patterns and Pillars 总览

## 两套系统的区别

- `Pattern / Seed Pattern`：满足卡面灵感或材料条件后，制作一件新 Gear。Seed Pattern 通常是直接安装的小型独立配方。
- `Pillar`：在设计新 Campaign 时加入的全局模块，会添加 Terrain、Hunt Event、Milestone、Minion 或故事。它不是战役中随机抽到的一张普通卡。

| 产品 | 安装 / 触发 | 内容与效果 |
|---|---|---|
| Pillar - Forge Priest | 战役设计时加入 `Godmetal Pilgrimage`，并把 `Godmetal Lodes` 加入 Terrain Deck | Showdown 出现该 Terrain 时，Forge Priest Minion 挑战幸存者；可获得 `Forge Priest Hammer` Rare Gear。Minion 与 Hammer 数值待卡面核验。 |
| Seed Pattern Survivor - Ingama | 按 Seed Pattern 规则把配方加入可用池 | `Feral Zanbato` Pattern + Gear；制作条件和效果待卡面核验。 |
| Seed Pattern - Jackel | 同上 | `Spina Sickle` Pattern + Gear；待核验。 |
| Pillar Survivor Fade | 战役设计时加入 Milestone：据点获得 Storytelling 后，用 `Baby and the Sword` 替换 1 张 Basic Hunt Event | 事件可产生 `Newborn` 与 `Sword of Silence` 两件 Rare Gear；具体分支待卡面核验。 |
| Mox the Healer | 安装 Beta Pillar | 含 1 Beta Pillar 与 1 Beta Starting Gear；属于测试规则，效果需按随盒卡，不视为最终 CoD 规则。 |
| Pillar - Percival | 战役设计时安装 Pillar Hunt Event | 含 1 Secret Fighting Art；事件与 SFA 效果待核验。 |
| Seed Pattern Survivor - Zaniyah | 按 Seed Pattern 规则安装 | `Stone Macuahuitl` Pattern + Gear；带 `Heroic` Living Glossary，具体效果待核验。 |
