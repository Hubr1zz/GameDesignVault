# Philosophy 卡概览

> 数据源主要来自 [Philosophies](https://kingdomdeath.fandom.com/wiki/Philosophies) 与各哲学条目。哲学卡通常包含：类型、Neurosis、Tenet Knowledge、rank 阈值和多个 rank 效果表。这里记录来源与功能摘要，详细 Knowledge 效果见 [[Knowledge卡效果索引]]。

## 哲学牌库类型

| 类型 | 功能 |
|---|---|
| Core | 战役核心怪物/核心主题带来的哲学。例如 `People of the Dream Keeper` 的核心哲学是 Dreamism。 |
| Starting | 起始哲学，代表幸存者基本恐惧和生存需求。GCE 中 Survivalism 是起始哲学。 |
| Tier 1 | 较容易理解的哲学。开局会随机加入两张 Tier 1。 |
| Tier 2 | 更复杂的哲学，通过 Collective Cognition 解锁后加入。 |
| Tier 3 | 高阶强力哲学，通过更高 Collective Cognition 解锁。 |
| Systemic | 由重要事件、原则或系统状态加入牌库的哲学。 |

## 使用方式总结

- 哲学卡不是单张“技能卡”，而是角色成长轨道。
- `Neurosis` 给出代价或行为偏执，避免哲学只提供正收益。
- `Tenet Knowledge` 是该哲学的核心知识，占用专门的 tenet slot。
- rank 表把 Hunt XP、lumi、CC、Knowledge、属性和事件后果串起来。
- Systemic 哲学尤其适合学习：它们由事件加入牌库，说明 KDM 会让“据点发生过什么”改变未来幸存者可选择的思想。
