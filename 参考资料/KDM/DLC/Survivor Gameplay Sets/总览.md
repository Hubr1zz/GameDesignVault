# Survivor Gameplay Sets 总览

## 10th Anniversary Survivors

通过 6 张 Pattern 引入 6 类 Gear：

| Gear | 来源 | 效果摘要 |
|---|---|---|
| Plated Shield | 完成同名 Pattern | 1/8+/3 Shield，Frail、Deflect 1；持有 deflect token 时获得 Sharp。 |
| Telcric Eye Tac | 完成同名 Pattern | 花 Activation 掷 3 个 Hit Location dice 并记录；下次被命中时选 1 个结果决定部位，弃其余结果。 |
| Tempered Axe | 完成同名 Pattern | 2/6+/6，Paired；使用 Axe Specialization 时，对所选 HL 的第二次 wound attempt 获得 Sharp。 |
| Tempered Dagger | 完成同名 Pattern | 3/7+/4，Paired；使用 Dagger Specialization 时，可弃掉其他已抽 HL，使对目标 HL 的第二次 wound attempt 按弃牌数获得 Luck。 |
| Tempered Spear | 完成同名 Pattern | 2/5+/5，Reach 2；Affinity Bonus 使该武器的 Spear Specialization 掷骰结果 +1。 |
| Vault Key Earrings | 完成同名 Pattern | 装备时选择自己的 1 个 Disorder，忽略其效果。 |
