# Indomitable Survivors 总览

## 系统功能

Indomitable Monster 是活得异常久、具备额外特征的高难怪物。满足对应挑战并击败它后获得专属 `Indomitable Resource`；该资源触发/完成一张 Pattern，制作一件高阶 Pattern Gear。单盒通常就是“1 资源 + 1 Pattern + 1 Gear”，不是完整新怪物。

## 获取案例

以 `Tachyon Nodachi Rubi` 为例：先把该盒的 Indomitable 规则安装到使用 Phoenix 的战役；完成卡面列出的高难条件并获得 `Neutron Seed`，再按 `Tachyon Nodachi Pattern` 的材料/灵感要求制作 Gear。不能仅因据点曾击败普通 Phoenix 就直接把武器加入 Storage。
