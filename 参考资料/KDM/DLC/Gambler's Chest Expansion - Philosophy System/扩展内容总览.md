# Gambler's Chest Expansion 全扩展入口

> 文件夹沿用早期“Philosophy System”名称，但这里覆盖整个 GCE。哲学专题从 [[Gambler's Chest Expansion - Philosophy System/总览|总览]] 开始。

## 提供内容

- 30 Lantern Year 战役 `People of the Dream Keeper`。
- Quarry：Crimson Crocodile、Smog Singers、The King；Encounter：Bone Eaters。
- Nemesis / Core / Finale 相关敌人：Atnas、The Gambler、Godhand 等，具体节点按战役时间线。
- 330+ Monster Bridge Cards、200+ Gear、6 Settlement Location、4 Settlement Event。
- 三套主要 Armor：Crimson Crocodile Armor、Smog Singer Armor、Death King Armor。

## 基础 1.6 没有的新模块

| 模块 | 功能 | 例子 |
|---|---|---|
| Arc Survivor | 以 Philosophy / Knowledge / CC 取代普通 Age 成长 | 详见 [[术语与流程]]。 |
| Encounter | Hunt 中途在独立小板上遭遇小型怪物，不是完整 Quarry Showdown | Bone Eaters 以群体形式出现，使用 Encounter 专属卡和 Critical Hit 结构。 |
| Scout | 第 5 名支援幸存者，不作为普通四人猎队成员直接参战 | 使用 Scout Gear 与 Scout Report，在狩猎/决战外围提供信息和支援，同时承担独立风险。 |
| Pattern / Seed Pattern | 满足灵感条件后，以特殊材料制作非工坊固定配方 Gear | 20+ Pattern、30+ Pattern Gear。 |
| Wanderer | 临时加入据点的具名访客，关系推进后分享能力并离开 | GCE 自带的 Wanderer 及后续独立小盒共用该框架。 |
| Character | 给符合条件的幸存者附加具名人物规则 | Character Card 可把普通幸存者塑造成具有持续能力/限制的角色。 |
| Narrative Sculptures | 以特定故事结果和装备形象呈现幸存者 | 模型本身不自动授予规则；对应事件、Pattern 或 Character 才是玩法入口。 |
