# GCE 失调卡

| Disorder | 来源 / 获取 | 具体效果 |
|---|---|---|
| Atelophobia | GCE Disorder 牌池；由 GCE 事件或抽 Disorder 指令获得 | 自己一次攻击中没有任何 Perfect Hit 时，承受 1 brain damage。 |
| Bloodlust | 同上 | 任一幸存者获得 bleeding token 时，自己遭受 Frenzy brain trauma；每轮最多触发 1 次。 |
| Brain Smog | 同上 | 不能 Surge，也不能 Concentrate。 |
| Directional Dyslexia | 同上 | 每次 Move 只能沿一条直线移动。 |
| Ergophobia | 同上 | 作为 Returning Survivor 时不产生 Endeavor；自己也不能 Endeavor。 |
| Pacifist | 同上 | 不能激活 Weapon 发动攻击；Frenzied 时忽略此限制。 |
| Phobophobia | 同上 | 自己行动开始时若 Insanity 为 0，获得 `Terrified` Survivor Status Card。 |
| Photophilia | 同上 | Gear Grid 中没有 Lantern 时不能 Depart。 |
| Schadenfreude | 同上 | 另一幸存者承受 Severe Injury 时，自己被 Knocked Down 并 +1 Insanity。 |
| Somniphobia | 同上 | Arrival 时失去一半 Survival，向下取整。 |
| Subjugated | 同上；狩猎 The King 时可移除 | 每当自己被 Knocked Down，同时变为 Dominated。Depart 去狩猎 The King 时移除此 Disorder。 |
| Weltschmerz | 同上 | 本 Lantern Year 尚未更新过 Death Count 时，不能 Depart。 |

## 来源
