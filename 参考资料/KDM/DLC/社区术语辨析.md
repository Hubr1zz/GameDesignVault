# KDM 社区术语辨析：膜具、金武器、钥匙

> 这三个中文词都不是能唯一映射到一条 KDM 官方规则的标准术语。以下按语境给出最可能解释，并标记置信度。

## “膜具”

### 最可能：`模具` 的错字（高置信）

如果上下文是 Kickstarter 进度、塑料件生产、开箱或模型质量，几乎肯定指 miniature 的注塑模具 / tooling。它只是生产状态，不是游戏组件或规则。

### 次可能：`Membrane Armor`（中置信）

如果上下文是 Frogdog、护甲套装或装备效果，可能指 **Membrane Armor**，有人把 membrane 直译成“膜”后简称“膜甲/膜装”。这是 Frogdog Expansion 的护甲线，不应写成“膜具”。公开旧讨论确认 Frogdog 的一套 Armor 曾更名为 Membrane Armor。

### 较低可能：Pariah 的 `Scab` 装备（低置信）

如果上下文提到把 population、organ 或幸存者身体做成武器，实际术语是 **Scab Pattern Gear**。它们是 Pariah 赠送的五件腐化仿制武器；“膜具”可能是非标准意译或听写误差，但没有查到社区普遍这样称呼。

## “金武器”

### 最可能：Gold Smoke Knight 相关装备的口头简称（中置信）

若上下文是核心战役最终阶段、Finale 或 LY30，通常是在说 **Gold Smoke Knight** 或它所代表的终局装备/强度，而不是一个正式的“金色稀有度”。KDM 没有通用的白、蓝、紫、金装备稀有度系统。

### 也可能：Blacksmith / Oxidized / Perfect 终盘武器（中低置信）

若说的是“做金武器”“终盘金装”，玩家可能泛指 Lantern Sword、Lantern Glaive、Dragon Slayer 等 Blacksmith 高阶武器，或 Watcher 后通过 `Oxidation` 制作的 Oxidized 武器。它是玩家按卡色、金属感或强度形成的非正式统称，必须结合具体卡名判断。

### 不是：统一的官方 Golden Weapon 类别（高置信）

当前规则中不存在名为 `Golden Weapon` 的通用装备类别或品质阶级。看到这个词时，不应直接据此推导制作规则。

## “钥匙”

### 游戏内 `Portcullis Key`（高置信）

核心随机狩猎事件 #79 `Dying Small Prospector` 可获得；在 #99 `Portcullis` 使用后开启门，并有机会获得 `Perfect Crucible`。这是实体规则中的任务型物品。

### GCE 的 `Master Key`（高置信）

King crest 的 Strange Resource，带 perfect / bone / iron / scrap 等关键词。其卡面效果是将它 archive，以忽略一个 `locked` requirement；Departing survivor 可以携带。它也可帮助进入 King / Kingdom Death 相关路线，但并非唯一入口。

### `Vault Key Earrings`（高置信）

10th Anniversary Survivors 带来的 Seed Pattern Gear。装备时选择自身 1 个 Disorder，并忽略其效果。若上下文是 Pattern、耳环或压制失调，指的是它。

### KDM Simulator 的 Dwelling / Master Key（高置信）

如果上下文是购买数字版、邀请码、房间人数或抢先内容，`Key` 是 **Kingdom Death: Simulator 的使用授权/商品档位**，不是桌游内资源。社区常说 Standard Key、Dwelling Key、Master Key；这与 GCE 的同名 Master Key 卡完全是两件事。

## 快速判断

| 上下文关键词 | 应优先理解为 |
|---|---|
| 开模、塑料、量产、sprue、交付 | 模型生产模具 |
| Frogdog、Armor、青蛙皮膜 | Membrane Armor |
| Pariah、population、organ、牺牲人口 | Scab Pattern Gear |
| Finale、LY30、烟、骑士 | Gold Smoke Knight |
| Blacksmith、Watcher、Oxidation | 终盘金属武器的玩家俗称 |
| Hunt Event #79/#99、Portcullis | Portcullis Key |
| King、locked requirement、Strange Resource | GCE Master Key |
| 数字版、邀请、房间、购买 | KDM Simulator Key |
